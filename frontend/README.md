# KrishiSetu AI - Web Application

## Overview
This directory contains the responsive web client for KrishiSetu AI, designed for farmers, field agricultural officers, and evaluators.

## Architecture & Technology Stack
- **Framework**: React 18+ (SPA with Vite / Next.js)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State & Data Fetching**: Standard React hooks & lightweight fetching client
- **Internationalization (i18n)**: Centralized translation architecture supporting Indian languages
- **Backend Communication**: Shared FastAPI REST endpoints (`/api/v1`)

## Key Client Capabilities (Planned)
- Farmer onboarding & farm profile management
- Interactive farm location picking (Current GPS, Map Pin, Manual Geocoding Search)
- Field leaf image upload and drag-and-drop analysis
- Disease identification dashboard with confidence visualization
- Micro-climate weather card and pest/outbreak risk level display
- Targeted agricultural intervention cards
- Audio narration ("Listen" button) for accessibility
- Historical analysis records and prediction feedback submission
- Judge / Demo Mode for simulated evaluations

## Current Status
**Phase 0 - Architectural Foundation.** No UI components or dependencies are installed yet. Implementation begins after shared API contracts are established.
